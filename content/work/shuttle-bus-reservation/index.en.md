**2023–2024**

A web-based seat reservation system developed for the university campus shuttle service. It supports assigned seating for four buses with 20 seats each and integrates with a custom student ID card reader to validate boarding eligibility.

## Development

I built the on-premises server infrastructure for the system and performed the on-site setup and validation.

Docker / Nginx / Python / Flask / Jinja2
