**期間:** 2025

宿泊事業を展開する企業から依頼を受け、宿泊施設の検索・予約ができるモバイルアプリを開発しました。

## Development

企画されたサービスをモバイルアプリとして実現するため、設計から実装までを担当しました。AndroidとiOSの両方へ対応するため、FlutterとDartによるクロスプラットフォーム構成を採用しました。

## Infrastructure

アプリ開発に加えて、宿泊施設を紹介するWebサイトのインフラ構築も担当しました。また、GitHub Actionsを利用してCI/CD環境を整備し、継続的にビルド・デプロイできる開発環境を構築しました。

## Technology

Flutter / Dart / Firebase / GitHub Actions
