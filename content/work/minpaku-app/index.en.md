**Period:** 2025

I developed a mobile application for searching and booking accommodation, commissioned by a company operating in the hospitality industry.

## Development

I handled the design and implementation of the application. Flutter and Dart were used to build a cross-platform application supporting both Android and iOS.

## Infrastructure

In addition to the mobile application, I built the infrastructure for a website introducing accommodation properties. I also established a CI/CD workflow with GitHub Actions to support continuous builds and deployments.

## Technology

Flutter / Dart / Firebase / GitHub Actions
